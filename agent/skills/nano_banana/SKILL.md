# Nano Banana Skill

This skill enables agentic image generation and inpainting using Nano Banana models.

## Usage
To execute a prompt:
1. Run the script `agent/skills/nano_banana/main.py`.
2. Call the `execute(prompt, options)` function inside the script to run generation or inpainting.
